# Eval harness output

Generated by `npm run eval` (PRD US-016). Everything here is git-ignored
except this file and `reports/`, which is the part worth keeping.

```
eval/
  runs/<timestamp>.json          one run: every delivery, moment and judge verdict
  reports/<timestamp>.md         that run, scored: per-moment table, totals, gates
  sessions/<timestamp>/<chattiness>/<session folder>/
                                 the ordinary session folder each replay wrote
  cache/<hash>.json              one cached judge verdict
```

- **`runs/`** is the raw record the report and the gates are computed from, so
  a scoring change costs no API calls: `npm run eval:report` rebuilds any past
  run's report from it.
- **`reports/`** is named after the run it scores, one to one, and is
  committed — a report is how a tuning change (US-023) is shown to have
  worked. It records the commit, the hash of every prompt and the estimated
  API cost, so two reports are comparable.
- **`sessions/`** holds the normal session folders — `transcript.md`,
  `board.md`, `candidates.jsonl`, … — which is where to look when a number in
  a report needs explaining.
- **`cache/`** is keyed by the card's words, the moment it was judged against
  and a hash of `server/prompts/judge.md`. Editing that prompt invalidates
  every verdict, which is the point of having it in the key; delete the folder
  to re-judge from scratch.

Usage:

```sh
npm run eval                             # the eval set at chattiness normal
npm run eval -- --chattiness all         # quiet, normal and active
npm run eval -- --fixtures moment-fact   # one conversation
npm run eval -- --no-judge               # replay and record, match nothing

npm run eval:report                      # re-score the newest run, no API calls
npm run eval:report -- 2026-10-28_091323 # re-score one run by its id

npm run eval:ceiling                     # the most recall the fixtures allow
npm run eval:ceiling -- --every 1        # ...if the observer looked every turn
```

Both exit non-zero when a gate fails: moment recall below 0.7, a false
interjection on `brainstorm` or `no-wake`, a delivery outside a pause, or a
replay that threw.

`npm run eval` calls the real Meta API for both the replays and the judge.
`npm run eval:report` calls nothing: it only reads `runs/`.

`npm run eval:ceiling` calls nothing either, and answers a different question:
not what Sotto caught but what it *could* have. A moment can only be delivered
inside its window, only in a pause, and only once the observer has looked —
and the observer looks after a board update, four final turns apart (PRD
US-009, US-012). Replaying the captures through the turn assembler alone
places all three on one timeline, so the ceiling on recall is measurable
before any run is paid for. It is an upper bound: the observer still has to
notice the moment and the score still has to clear a threshold. See US-023 in
`ralph/prd.json` and `reports/2026-10-28_185157-notes.md` for what it says
about the current cadence.
