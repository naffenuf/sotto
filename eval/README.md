# Eval harness output

Everything in this folder except this file is generated by `npm run eval`
(PRD US-016) and is git-ignored.

```
eval/
  runs/<timestamp>.json          one run: every delivery, moment and judge verdict
  sessions/<timestamp>/<chattiness>/<session folder>/
                                 the ordinary session folder each replay wrote
  cache/<hash>.json              one cached judge verdict
```

- **`runs/`** is the raw record the report and the gates are computed from
  (US-016 part 2), so a scoring change costs no API calls.
- **`sessions/`** holds the normal session folders — `transcript.md`,
  `board.md`, `candidates.jsonl`, … — which is where to look when a number in
  a report needs explaining.
- **`cache/`** is keyed by the card's words, the moment it was judged against
  and a hash of `server/prompts/judge.md`. Editing that prompt invalidates
  every verdict, which is the point of having it in the key; delete the folder
  to re-judge from scratch.

Usage:

```sh
npm run eval                             # the eval set at chattiness normal
npm run eval -- --chattiness all         # quiet, normal and active
npm run eval -- --fixtures moment-fact   # one conversation
npm run eval -- --no-judge               # replay and record, match nothing
```

This calls the real Meta API for both the replays and the judge.
