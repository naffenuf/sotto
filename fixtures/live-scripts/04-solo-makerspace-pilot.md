# Solo script: Planning a makerspace pilot

**Setting:** You’re planning a short pilot for a community makerspace. Start a microphone session and speak naturally, using your own name. The lines are prompts, not computer responses: react to Sotto and adapt if it contributes. Watch the stage during pauses; the current build does not speak aloud.

**You:** Hi, I’m [your name]. I’m planning a pilot for a community makerspace, and I want to figure out a simple first version before we make any big commitments.

**You:** The pilot has a firm limit of eight participants. We can use the library’s workshop room, and its staff will help us set up tables. For this first session, I only want activities that use hand tools.

**You:** I’d like the group to leave with one small wooden shelf. We can prepare the pieces in advance and let participants sand and assemble them with guidance.

*[Pause briefly, then continue.]*

**You:** I’ll ask a volunteer to demonstrate each step, and I’ll put a printed instruction sheet at each table. I want people who have never built anything to feel comfortable trying.

**You:** Let’s register twenty participants for the pilot and have all twenty attend the workshop. A bigger group will give us more feedback.

*[Stop speaking and watch the stage for up to 20 seconds. If Sotto contributes, respond naturally. If it doesn’t, continue.]*

**You:** I should check what materials we already have before buying more. Sandpaper and screws are probably the only things we need to purchase.

**You:** Sotto, suggest two simple ways to find out whether beginners enjoyed the session.

*[Wait for the answer and react naturally.]*

**You:** I’ll ask the library about accessibility and confirm that the room is available. I’ll also ask the volunteer which hand tools they can bring.

**You:** I’d like to finish the event with a short show-and-tell, but nobody has to present if they don’t want to.

**You:** That’s enough planning for now. I’ll review the invitations and materials list before booking anything.

## What to observe

- Did Sotto attach your name to the transcript after the introduction?
- Did it spot the conflict between the eight-person limit and having twenty participants attend? How long after the proposal did its card appear, and was it still relevant?
- Did the explicit question get a useful answer? Open **details** on the answer card to see its full response.
- Did the discussion notes capture the participant limit and the main decisions?
- After stopping, open the discussion’s **Backstage** tab to inspect candidates and decisions. The session’s timing log can show when the observer started and when a candidate was delivered.

This is a test of the faster path for existing interjection types. The current observer is not yet designed to offer unsolicited brainstorming ideas, and Sotto need not contribute at every pause.
